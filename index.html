Adaptive labels on a bar chart

Interactive prototype. Edit any label below and it updates in real time. The chart auto-picks the best label treatment based on column width and label length.

Adaptive label rule

Horizontal → rotate (short) → truncate + hover (long)

The longest visible label decides the mode: it stays horizontal when it fits (≤2 lines); rotates ~40° when columns get narrow and the longest label is ≤24 chars; and wraps 2 lines + truncates “…” + hover when labels are long. Toggle pagination off to fit all bars in one view and watch short labels auto-rotate.
